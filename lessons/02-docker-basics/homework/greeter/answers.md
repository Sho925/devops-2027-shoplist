1. docker build -t greeter:v1 .
2. docker run -d -p 9000:8000 --name greeter greeter:v1
3. כדי לשנות את הברכה שתוצג מ-"Hello" ל-"Shalom" בעת הרצת ה-Docker container, תוכל להוסיף משתנה סביבה לפקודה. השימוש במשתנה סביבה תלוי באפליקציה שכתבת,
4. אם הכל הוגדר נכון ותוכנית ה-greeter שלך מעבדת את המשתנה `GREETING` ומחזירה את הברכה שתוגדר בו, אז הכתובת `http://localhost:9000/hello/Rivka` תחזיר ברכה שמכילה את המילה "Shalom" יחד עם השם "Rivka".

למשל, אם התוכנית מייצרת פלט כמו "Shalom, Rivka!", אז זו תהיה התוצאה שתחזיר הכתובת.

5.כאשר משנים שורה בקובץ `app.py`, כל שלב בבניית ה-Docker container מטופל לפי השינויים שנעשו בקוד.

במקרה של Docker, השיטה היא להשתמש במנגנון cache כדי לייעל את תהליך הבנייה. אם השינוי שנעשה בקובץ `app.py` הוביל לשינוי בקוד, השלבים שיבנו את השכבות שנמצאות מעליו בעץ הבנייה ישאלו מחדש וירוצו מחדש, בעוד שכבות מתחת לא יהיו מושפעות והן יסומנו כ-CACHED.

לסיכום:
•כל השלבים שנעשו לפני השינוי בקובץ `app.py` (שכבות שנבנו לפני השינוי) יסומנו CACHED.
•השלבים שקשורים לקובץ `app.py` ולאחר מכן, ירוצו מחדש.

הסיבה לכך היא ש-Docker משתמש בחשיבה של Layering, וכאשר שינוי מתבצע באחת השכבות, השכבות שאחריהן צריכות להתעדכן כדי לשקף את השינויים שנעשו.
